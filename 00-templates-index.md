# BSV workshop templates index

This repository provides minimal Markdown templates for BSV blockchain workshops and reusable primitive modules.

## structure

- workshop: container for the complete workshop template and section files.
- primitives: reusable primitive modules that can be nested in workshops.
- demos and use cases: minimal shells to document demonstrations and applications.
- code: placeholder for code showcase notes and run instructions.
- shared: glossary and references used across files.
- meta: changelog and internal notes.

## editorial notes

- Use British English and plain, clear language.
- Refer to the network as “BSV blockchain” and the token as “BSV”.
- Avoid unsubstantiated claims and keep statements accurate and verifiable.
