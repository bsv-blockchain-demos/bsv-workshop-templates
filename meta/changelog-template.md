## Update guidelines

### When to update this changelog
- Any modification to workshop content or structure
- Addition or removal of files or sections
- Changes to technical accuracy or educational approach
- Updates to references or external links

### Changelog format
Each version entry should include:
- Version number following semantic versioning
- Date of changes
- Author or contributor information
- Status (Draft, Review, Final)
- Categorised list of changes

### Version numbering
- **Major version** (X.0.0): Significant structural changes or complete rewrites
- **Minor version** (0.X.0): New content, sections, or substantial updates
- **Patch version** (0.0.X): Minor corrections, link updates, or small improvements
