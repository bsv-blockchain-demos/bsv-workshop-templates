# Ecosystem overview

## Purpose
Provide neutral context about the types of actors and services that exist within the BSV blockchain environment.

## Learning outcomes
- Identify the basic roles of miners, wallet providers, and application developers.
- Understand the function of supporting services like indexers and payment processors.
- Recognise the distinction between protocol-level features and application-layer services.

## Network participants
- Miners: validate transactions and produce blocks according to consensus rules.
- Node operators: maintain copies of the blockchain and relay transactions.
- Wallet providers: offer key management and transaction building services.
- Application developers: build services that use BSV blockchain functionality.

## Supporting services
- Block explorers: provide web interfaces for viewing transaction and block data.
- Indexing services: maintain searchable databases of blockchain data.
- Payment processors: handle BSV payments for merchants and applications.
- Exchange platforms: facilitate trading between BSV and other assets.

## Development resources
- Software development kits (SDKs): libraries for common programming languages.
- Documentation sites: technical specifications and integration guides.
- Testing networks: environments for development and testing without using mainnet BSV.
- Community forums: spaces for technical discussion and support.

## Standards and protocols
- Core protocol: defines transaction validation and block production rules.
- Application protocols: conventions for specific use cases built on the base layer.
- Interoperability standards: common formats for cross-application compatibility.

## What this section covers
- Factual roles and services available in the ecosystem.
- Context for understanding how workshop components fit within the broader environment.

## What this section does not cover
- Endorsements or recommendations for specific services.
- Business model analysis or commercial comparisons.
- Regulatory or compliance guidance.
