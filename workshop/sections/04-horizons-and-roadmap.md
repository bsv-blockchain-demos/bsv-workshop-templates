# Horizons and roadmap

## Purpose
Provide factual context about areas of active development and exploration within the BSV blockchain environment.

## Learning outcomes
- Understand the distinction between current capabilities and areas under development.
- Recognise the importance of staying informed about protocol and tooling evolution.
- Know where to find current information about development priorities.

## Current capabilities
- Transaction processing and validation according to established consensus rules.
- Script execution for programmable spending conditions.
- Data storage through various transaction output formats.
- Supporting infrastructure for wallets, indexing, and application development.

## Areas of active development
- Tooling and SDK improvements for common development workflows.
- Indexing and query services for efficient data access.
- Standards development for interoperability between applications.
- Testing and simulation environments for application validation.

## Infrastructure considerations
- Scaling considerations for increased transaction throughput.
- Performance optimisation for indexing and data retrieval services.
- Integration patterns for enterprise applications.
- Security practices for production deployments.

## Information sources
- Protocol specifications and technical documentation.
- Community forums and developer resources.
- Service provider announcements and release notes.
- Research publications and case studies.

## What this section covers
- Factual information about current development directions.
- Context for understanding how workshop material fits within ongoing development.

## What this section does not cover
- Specific timelines or commitments for future features.
- Investment or business strategy recommendations.
- Predictions about adoption or market developments.

## References
- See shared references for links to current documentation and community resources.
- Workshop participants should verify current information from authoritative sources.
