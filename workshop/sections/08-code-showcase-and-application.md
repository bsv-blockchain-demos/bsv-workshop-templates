# Code showcase and application

## Purpose
Present a working application that demonstrates the primitive concepts covered in this workshop.

## Learning outcomes
- See how theoretical concepts translate to working code.
- Understand the basic architecture for BSV blockchain applications.
- Know the key components and files needed for implementation.
- Be able to run and test the example application locally.
