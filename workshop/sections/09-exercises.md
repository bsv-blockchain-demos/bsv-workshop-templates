# Exercises

## Purpose
Provide structured, hands-on tasks that allow participants to apply concepts from the workshop material.

## Learning outcomes
- Apply theoretical knowledge through practical implementation.
- Build confidence with BSV blockchain tools and workflows.
- Verify understanding through working code or successful transactions.
- Connect individual concepts to complete application patterns.

## Exercise structure
Each exercise should include:
- **Objective**: clear statement of what the exercise demonstrates.
- **Prerequisites**: required setup, accounts, or prior exercises.
- **Task description**: step-by-step instructions for completion.
- **Success criteria**: observable outcomes that indicate completion.
- **Verification**: method to confirm the exercise worked correctly.
- **Extensions**: optional additional tasks for advanced participants.

## Exercise categories
- **Basic implementation**: implement core functions using provided frameworks.
- **Transaction building**: construct and broadcast transactions with specific features.
- **Data verification**: read and validate information from the blockchain.
- **Integration tasks**: connect multiple components or services.
- **Troubleshooting**: identify and fix issues in provided code.

## Common exercise patterns
Based on the workshop primitive, exercises typically include:
- Implement core functionality using provided SDKs or libraries.
- Create and validate transactions that demonstrate the primitive features.
- Read data from the blockchain and verify its integrity.
- Build simple applications that combine multiple operations.
- Test error cases and edge conditions.

## Completion guidelines
- Work through exercises in the suggested order when dependencies exist.
- Verify each step before proceeding to avoid compounding issues.
- Use provided troubleshooting resources when problems occur.
- Ask for assistance when stuck rather than struggling independently.
- Share successful solutions with other participants when appropriate.

## Time estimates
- Provide realistic time estimates for each exercise.
- Account for setup time, implementation work, and verification steps.
- Include buffer time for troubleshooting common issues.

## Assessment criteria
- Functional completion: does the implementation work as specified?
- Understanding demonstration: can the participant explain their solution?
- Code quality: is the implementation clear and appropriate?
- Extension work: did the participant attempt additional challenges?

## What this section covers
- Structured tasks aligned to workshop learning objectives.
- Clear instructions that participants can follow independently.
- Verification methods to confirm successful completion.

## What this section does not cover
- Complete solutions or answer keys (these should be separate materials).
- Advanced topics beyond the workshop scope.
- Production-quality implementation requirements.
